# CyberAI

**Assistant CTF intelligent** orienté analyse statique, génération d'hypothèses et expérimentation.

CyberAI aide à comprendre un challenge (surtout **pwn** pour l'instant), détecte des primitives intéressantes et propose des pistes d'exploitation classées par confiance.

> ⚠️ Outil destiné à un usage **légal et éthique uniquement** (CTF, labs, recherche autorisée).
